# Content Thumbnails

홈 화면 컨텐츠 썸네일 이미지 에셋. 코드 쪽 모델은 `src/components/home/thumbnail.ts` 참고.

## 폴더 규칙

| 폴더       | 용도                                                       |
| ---------- | ---------------------------------------------------------- |
| `ko/`      | 한국어 전용 에셋 (텍스트가 이미지에 박힌 baked 디자인)     |
| `en/`      | 영어 전용 에셋 (ko와 동일한 파일명으로 저장)               |
| `shared/`  | 전 언어 공용 에셋 (텍스트 없는 배경 일러스트)              |

baked 에셋은 **ko/와 en/에 같은 파일명**으로 두 벌 모두 있어야 한다.
빠지면 해당 로케일에서 이미지가 404로 깨진다.

## 슬롯별 권장 규격

| 슬롯     | 비율  | 권장 해상도   | 쓰이는 곳                    |
| -------- | ----- | ------------- | ---------------------------- |
| `hero`   | 2:1   | 1440 × 720    | 메인 상단 슬라이딩 배너      |
| `wide`   | 2:1   | 1440 × 720    | 카드/퀴즈 섹션 빅 배너       |
| `poster` | 3:4   | 600 × 800     | NEW 등 가로 스크롤 포스터    |

## 텍스트 모드

- `overlay`: 이미지는 배경, 문구는 i18n 텍스트로 코드가 올림.
  좌측 약 50%는 텍스트용 여백(단색에 가깝게)으로 비워서 제작.
- `baked`: 타이포가 이미지에 포함. 코드는 문구 오버레이를 렌더링하지 않음.
  로케일별(ko/, en/) 버전 필수.

## 새 썸네일 등록 절차

1. 이미지를 규칙에 맞는 폴더에 저장 (예: `ko/announce-card.webp` — 용량을 위해 WebP 권장)
2. `src/app/[locale]/page.tsx`의 `SECTIONS`에서 해당 컨텐츠의 `thumbnail`을 설정:

```ts
thumbnail: {
  kind: "image",
  images: { hero: "announce-card.webp" }, // 같은 파일을 여러 슬롯에 써도 됨
  localized: true,   // shared/ 에셋이면 false
  textMode: "baked", // 배경용이면 "overlay"
}
```
